☁️ 跨裝置同步（GitHub Gist）
GitHub → Settings → Developer settings → Personal access tokens → Tokens (classic) → Generate new token，只勾選「gist」權限，把權杖貼在下面。每台裝置都要貼同一個權杖。
🔊 發音設定
預設會依照瀏覽器、作業系統及這台裝置實際提供的韓文語音，自動挑選較合適的選項；也可以在下方手動指定。手動選擇會保存在這台裝置。
正在偵測可用語音…
語音清單會因裝置、作業系統及瀏覽器而不同；網頁會先依環境推薦，再以裝置實際提供的語音為準。若自動推薦的語音無法播放，可從選單改選其他韓文語音，或選回「自動偵測」。
✨ AI 功能（Gemini 免費額度）
用於自動翻譯、自動標籤、學習建議。到 aistudio.google.com/apikey 建立免費金鑰。金鑰只存在這台裝置，每台裝置要各貼一次。免費額度的內容可能被 Google 用來改進產品。
🎧 書附音檔（只存在這台裝置）
選取書附的 mp3，網站會在你的瀏覽器裡，依靜音自動切成一段一段，你標上每一段是哪個音之後存起來。音檔不會上傳到任何地方，也不會跟著同步，每台裝置要各匯入一次。有匯入的音節，點發音表時會播你的錄音，沒有的才用裝置語音。
📦 依對照表，從 zip 一次匯入
① 先選對照表（你整理的 Excel，或 CSV／TSV 都可以）。② 再選音檔 zip，可以一次選好幾個。網站會依對照表自動切段、標好內容，並寫出匯入報告。如果 zip 裡的檔案本身就是「가.m4a」這種一個音節一個檔、檔名以韓文音節開頭，可以不選對照表，直接做 ②。
